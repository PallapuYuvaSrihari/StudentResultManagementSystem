# Student Result Management System

A full-stack web application designed to manage and publish student academic results efficiently, built with **Spring Boot** and **React**.

## 🚀 Tech Stack
* **Frontend:** React (TypeScript / Vite)
* **Backend:** Java, Spring Boot, Spring Data JPA
* **Database:** MySQL / H2 Database
* **Version Control:** Git & GitHub

## 📂 Project Structure
* `apps/client` - Contains the React frontend application.
* `server` - Contains the Spring Boot backend REST API server.

## ✨ Features
* Admin dashboard to manage and update student records and marks.
* Secure RESTful API architecture connecting the frontend and backend.
* Responsive and clean user interface for viewing results.
